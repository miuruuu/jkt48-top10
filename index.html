    Gambar diunduh dulu, lalu lampirkan di tweet.
    info: share ke x emang agak makan waktu. x nggak ngizinin web mana pun nempelin foto ke tweet (kecuali lewat api yang nggak gratis dan nggak murah), jadi lu harus salin atau seret fotonya sendiri. ini web iseng, bukan pt, bukan jagoan, ya gini adanya, maapin.
    Tip: pasang X sebagai aplikasi, lalu foto masuk lewat tombol Bagikan
    1. Buka x.com di Chrome atau Edge, lalu pasang sebagai aplikasi (ikon pasang di kolom alamat, atau menu ⋮ → Simpan dan bagikan → Instal halaman sebagai aplikasi).
    2. Kembali ke situs ini, klik Bagikan lewat…. Di menu share Windows akan ada pilihan X.
    3. Pilih X: kotak tweet terbuka dengan fotonya sudah terlampir, tanpa file tersimpan.

    X mendaftarkan dirinya sebagai tujuan share untuk gambar (bisa kamu lihat di manifest-nya), tapi ini bergantung pada browser dan sistem operasimu, dan berapa foto yang diterima ditentukan X. Kalau X tidak muncul di daftar, pakai cara lain di atas.

    Ekstensi Chrome (opsional): tempel semua foto ke tweet otomatis
    1. Unduh ekstensi (.zip) lalu ekstrak ke satu folder.
    2. Buka chrome://extensions, nyalakan Developer mode, klik Load unpacked, pilih folder tadi.
    3. Muat ulang situs ini. Tulisan "Ekstensi aktif" akan muncul di atas. Klik Post ke X dan foto akan menempel sendiri di kotak tweet.

    Disclaimer: ekstensi ini buatan penggemar, tidak resmi, dan tidak berafiliasi dengan X atau JKT48. Ia hanya berjalan di situs ini dan x.com, hanya menyimpan fotomu sementara di browser, dan tidak mengirim apa pun ke server. Karena X bisa mengubah tampilannya kapan saja, ekstensi bisa berhenti bekerja. Pakai atas risikomu sendiri dan baca kodenya dulu kalau ragu.
